#### <!Doctype html> 
- Always used & is the first line of code written at any Html file. This is used to tell the browser what version of HTML(5) its written in.
-- Its not a Html tag so it has no closing bracket.

#### Html tag
- <html></html> - used to tell the browser that we have use html to code this page.

#### Head Tag
- <head></head>- is used to store information about the to tell the browser what to do and what files like css to access. Everything in the head tag is not seen on the webpage
- --title Tage
- -<title></title>- used to put title of the document on the browser tab.

#### Body tag
- <body></body> this tag is used to add teh contents to the webpage, evrything you want to display goes in the body tag!

#### h1,h2,h3,h4,h5 & h6
- The header tags/elements used to denote headings and sub heading h1 to h3 are used a headings and 4 to 6 as subheadings.

#### P <p> tag
-the <p></p> - tag used to denote paragraph or sentence. 
--- the <em>italicise</em> used to italicise words like <b>bold</b> tag used to make words letters stand out in bold text on html document.

#### img tag
-image tag is one of the ways to display a picture or pictures to a web page. 
<img src="https://www.yourtango.com/sites/default/files/2020/golden-retriever.jpg"/> - for example will show pictutre of a cute dog.

#### anchor tag 
- <a href="https://google.com">click here</a> - this tag is used to link yo other sites for example.
- - the anchor tag uses a href(hyper reference link) is an attribute specifies the URL of the page the link goes to, this is placed inside the first anchor tag.#
    -- further more inbetween the the anchor tags <a> click here </a> one would put a clickable set of characters for example "click here".
    -- to make the link go to another tab in the browser we would use the target="_blank"  attribute to specify where to open the linked document, in this case it would open a new tab to the link provided in the browser.
